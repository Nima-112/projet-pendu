# projet-pendu# Projet Pendu
 
Jeu du pendu en Python (console), réalisé en binôme.
 
## Lancer le jeu
    python main.py
 
## Lancer les tests
    python -m unittest -v
 
## Organisation
- affichage.py : affichage et saisie (Personne A)
- jeu.py       : règles du jeu (Personne B)
- main.py      : programme principal
- test_jeu.py  : tests unitaires
